# Claude Code Secret Mission: 10 ภารกิจลับ ฉบับผู้เริ่มต้น

## ปฏิบัติการออนไลน์เรียนฟรี 5 วัน วันละ 2 ชั่วโมง สำหรับเอเจนต์หน้าใหม่ที่ไม่เคยใช้ AI Coding Agent มาก่อน จากศูนย์จนมีแอปของตัวเองที่ Deploy ขึ้นออนไลน์จริง

**รูปแบบปฏิบัติการ:** Online Live ผ่าน Zoom
**วันเปิดปฏิบัติการ:** 21-25 กันยายน 2569 (5 วัน)
**เวลาปฏิบัติการ:** 20:00-22:00 น. วันละ 2 ชั่วโมง
**ระยะเวลารวม:** 10 ชั่วโมง (5 วัน x 2 ชั่วโมง)
**ค่าเข้าร่วมภารกิจ:** ฟรี ไม่มีค่าใช้จ่าย
**ระดับเอเจนต์:** Rookie (เริ่มจากศูนย์ ไม่ต้องมีพื้นฐาน AI Coding มาก่อน)
**ภารกิจเสริม:** มีให้ แต่ไม่บังคับส่ง
**แฟ้มบันทึกย้อนหลัง:** มีวิดีโอให้ทบทวนทุกวัน
**ผู้บัญชาการภารกิจ:** อ.สามิตร โกยม
**ประสบการณ์:** สอนและพัฒนาซอฟต์แวร์กว่า 15 ปี

## ภารกิจนี้คืออะไร

Claude Code ไม่ได้เป็นเพียงเครื่องมือสำหรับถาม AI ให้ช่วยเขียนโค้ด แต่ทำหน้าที่เสมือน **AI Coding Agent** ที่เข้าใจโครงสร้างของโปรเจกต์ อ่านไฟล์ แก้ไข Source Code รันคำสั่ง ทดสอบระบบ และทำงานร่วมกับ Development Workflow ได้

ปฏิบัติการนี้ตัดทอนจากหลักสูตรเต็ม 12 บทเรียน ให้เหลือ **10 ภารกิจที่จำเป็นที่สุดสำหรับเอเจนต์หน้าใหม่** โดยยึดหลักว่าผู้เข้าร่วมต้องได้ผลลัพธ์จริงตั้งแต่วันแรก และเมื่อปิดปฏิบัติการจะมี **แอปของตัวเองที่สร้างจากศูนย์และ Deploy ขึ้นออนไลน์บน URL จริง** พร้อม Workflow ส่วนตัวที่ใช้ทำงานได้ทันที

เนื่องจากเวลาในสนามมีเพียงวันละ 2 ชั่วโมง ปฏิบัติการนี้จึงเน้น **ดูผู้บัญชาการทำ แล้วลงมือตามไปพร้อมกัน** มากกว่าการบรรยายทฤษฎี และแยกหัวข้อออกเป็นสองระดับชัดเจน คือ **ปฏิบัติจริงในคาบ** กับ **แฟ้มข้อมูลเพิ่มเติม**

## ใครควรรับภารกิจนี้

- นักพัฒนาที่ **ยังไม่เคยใช้ Claude Code หรือ AI Coding Agent มาก่อนเลย**
- คนที่เคยใช้ AI ช่วยเขียนโค้ดผ่านหน้าเว็บแชท แต่ยังไม่เคยใช้ผ่าน Terminal
- นักศึกษาหรือผู้เริ่มต้นสายโปรแกรมมิ่งที่อยากมีผลงานจริงขึ้นออนไลน์ไว้ใส่ Portfolio
- Developer ที่อยากลองก่อนตัดสินใจว่าจะนำ Claude Code ไปใช้กับงานจริงหรือไม่
- ผู้ที่สนใจหลักสูตรเต็ม 12 บทเรียน และอยากทดลองปฏิบัติการส่วนพื้นฐานก่อน

> **ภารกิจนี้ไม่เหมาะกับ:** เอเจนต์ที่ใช้ Claude Code คล่องอยู่แล้ว และต้องการเนื้อหาระดับ Hooks, Subagents, Agent Teams, Automation หรือ CI/CD ควรข้ามไปหลักสูตรเต็ม 12 บทเรียนแทน

## เป้าหมายของปฏิบัติการ

- เพื่อให้เอเจนต์ติดตั้งและใช้งาน Claude Code CLI ผ่าน Terminal ได้ด้วยตนเอง แม้ไม่เคยใช้มาก่อน
- เพื่อให้อ่านสถานะบริบทของตัวเองออก คุมค่าใช้จ่าย และเลือกโมเดลให้เหมาะกับงานได้ตั้งแต่วันแรก
- เพื่อให้สั่ง Claude Code อ่าน วิเคราะห์ และแก้ไขไฟล์ในโปรเจกต์จริงได้อย่างปลอดภัย
- เพื่อให้สร้างแฟ้มบริบท `CLAUDE.md` ให้ AI เข้าใจโปรเจกต์โดยไม่ต้องอธิบายซ้ำทุกครั้ง
- เพื่อให้เข้าใจ Plan Mode และ Agentic Loop และรู้ว่าเมื่อใดควรปล่อยให้ AI ลุยเอง เมื่อใดต้องเข้าควบคุม
- เพื่อให้ใช้ Claude Code ช่วยจัดการงาน Git ตั้งแต่ตรวจ Code Change จนถึงสร้าง Pull Request
- เพื่อให้สร้าง Claude Skills ของตัวเอง และหยิบ Skill สำเร็จรูปจากคลังมาใช้เป็น
- เพื่อให้ต่อ Claude Code เข้ากับบริการภายนอกผ่าน MCP และใช้ทำงานจริงได้
- เพื่อให้เริ่มโปรเจกต์ใหม่จากศูนย์ ตั้งแต่วางโครงสร้างจนเชื่อมฐานข้อมูลได้จริง
- เพื่อให้ Deploy แอปขึ้นออนไลน์ ตั้งค่า Environment Variables อย่างปลอดภัย และแก้ปัญหาที่พบบ่อยตอน Deploy ได้

## จุดเด่นของปฏิบัติการนี้

- **เริ่มจากศูนย์จริง ๆ:** มีช่วงสอนติดตั้งสดใน Day 1 ไม่ทิ้งเอเจนต์คนไหนไว้ข้างหลัง
- **ได้ผลลัพธ์ตั้งแต่วันแรก:** จบ Day 1 เอเจนต์สั่ง Claude Code แก้ไฟล์ในโปรเจกต์ตนเองได้ และคุมบริบทกับค่าใช้จ่ายเป็นแล้ว
- **สอนเรื่องค่าใช้จ่ายตั้งแต่ต้น:** ผู้เริ่มต้นส่วนใหญ่เจอปัญหาคุยยาวจนโควตาหมดและ AI เริ่มมั่ว ปฏิบัติการนี้ยกเป็นภารกิจเต็มตั้งแต่วันแรก
- **จบด้วยผลงานที่แชร์ได้จริง:** ไม่ใช่แค่ความรู้ แต่ได้แอปที่ขึ้นออนไลน์บน URL สาธารณะ ส่งให้เพื่อนเปิดดูหรือใส่ Portfolio ได้ทันที
- **MCP ได้ใช้จริง ไม่ใช่แค่ดูสาธิต:** ต่อ Supabase และ Vercel เข้ากับ Claude Code แล้วใช้ทำงานในคาบเดียวกัน
- **แยกชัดว่าอะไรต้องลงมือ อะไรแค่เปิดแฟ้มดู:** ทุกภารกิจระบุไว้ชัดเจน ลดความสับสนของผู้เริ่มต้น
- **ภารกิจเสริมไม่บังคับ:** มีโจทย์ให้ฝึกต่อ แต่ไม่กดดัน ลุยตามจังหวะของตัวเองได้
- **มีแฟ้มบันทึกย้อนหลังทุกวัน:** ตามไม่ทันในสนาม ย้อนดูได้
- **ใช้งานจริงสองแบบ:** Day 1-3 ฝึกกับโปรเจกต์ที่มีอยู่แล้วของตัวเอง Day 4-5 สร้างแอปใหม่ตั้งแต่โฟลเดอร์เปล่าจนขึ้นออนไลน์

## ภารกิจที่ 1 - เริ่มต้นใช้งาน Claude Code CLI

**รหัสภารกิจ: FIRST CONTACT** · Day 1 · 35 นาที

ทำความรู้จักกับ Claude Code และสั่งงาน AI Coding Agent ผ่าน Terminal เป็นครั้งแรก

### ปฏิบัติจริงในคาบ

- การติดตั้งและตั้งค่า Claude Code CLI และตรวจสุขภาพการติดตั้งด้วย `claude doctor`
- ทำความเข้าใจการทำงานของ Claude Code ผ่าน Command Line
- การสั่งงานด้วยภาษาธรรมชาติ พิมพ์ภาษาไทยได้
- ทำความเข้าใจว่า Claude Code อ่าน Codebase อย่างไร
- การให้ Claude Code แก้ไขไฟล์ในโปรเจกต์ และอ่านสิ่งที่จะเปลี่ยนก่อนอนุมัติ
- **โหมดการอนุญาต กด Shift+Tab วนดู** ตั้งแต่ถามก่อนทุกครั้ง แก้ไฟล์ได้เลย Plan จนถึงปล่อยอัตโนมัติ และเหตุผลที่ผู้เริ่มต้นควรอยู่โหมดแรกก่อน
- แนวทางการใช้งาน AI Agent กับ Source Code อย่างปลอดภัย

### แฟ้มข้อมูลเพิ่มเติม

- การมอบหมาย Coding Task ที่ซับซ้อนให้ AI Agent
- การสั่ง Claude Code รัน Command ในเครื่อง

Skills คือการรวบรวม Instructions, Constraints, Best Practices และ Workflow ให้อยู่ในรูปแบบที่เรียกใช้ซ้ำได้ ต่างจากแฟ้มบริบทตรงที่ Skill จะถูกหยิบมาใช้เฉพาะตอนที่เกี่ยวข้อง จึงไม่กินบริบททุกครั้งที่คุย

### ปฏิบัติจริงในคาบ

- แนวคิดของ Claude Skills และต่างจาก CLAUDE.md อย่างไร
- โครงสร้าง Skill: โฟลเดอร์ที่มีไฟล์ SKILL.md
- **หัวใจอยู่ที่ description** เพราะ Claude ใช้บรรทัดนี้ตัดสินใจว่าจะหยิบ Skill มาใช้เมื่อไร
- `/skills` ดูรายการที่มี และเรียกใช้แบบเจาะจง
- **ติดตั้ง Skill สำเร็จรูปจากคลังที่มีคนทำไว้แล้ว** ไม่ต้องเขียนเองทุกอย่าง
- **สร้าง Skill ชิ้นแรกของตัวเอง: Skill สัมภาษณ์โจทย์** เปลี่ยนสิ่งที่ทำมือใน Day 3 ให้เป็นอาวุธถาวรที่เรียกใช้ได้ทุกโปรเจกต์
- สร้าง Skill ตรวจงานก่อน Commit ไว้ใช้ใน Final Mission

### แฟ้มข้อมูลเพิ่มเติม

- การกำหนด Constraint และ Best Practices ใน Skill
- การแชร์ Skill ให้ทีมใช้ร่วมกันผ่าน repo
- การจัดวาง Skill ให้ AI เครื่องมืออื่นในทีมใช้ได้ด้วย

### ผลลัพธ์ของภารกิจ

เอเจนต์มีอาวุธประจำตัวอย่างน้อย 1 ชิ้นที่ Claude Code หยิบมาใช้เองได้อย่างสม่ำเสมอ และรู้ว่าจะไปหาของสำเร็จรูปมาใช้เพิ่มได้จากที่ไหน

- ให้ Claude วางโครงสร้างโปรเจกต์ด้วย Plan Mode ก่อนสร้างไฟล์จริง

## ภารกิจที่ 9 - Deploy ขึ้นโลกออนไลน์

**รหัสภารกิจ: LAUNCH DAY** · Day 5 · 45 นาที

แอปที่รันได้แค่บนเครื่องตัวเองยังไม่มีใครเปิดดูได้ ภารกิจนี้พาแอปจาก Day 4 ขึ้นออนไลน์ พร้อมเรียนรู้เรื่องที่มือใหม่พลาดบ่อยที่สุดตอน Deploy

### ปฏิบัติจริงในคาบ

- ตั้งค่า Environment Variables อย่างปลอดภัย ไม่ให้ค่าเชื่อมต่อหลุดเข้า Git
- Push ขึ้น GitHub แล้ว Deploy บน Vercel
- **ต่อ Vercel MCP เพื่อดูสถานะการ Deploy และอ่าน Build Log จากใน Claude Code** แล้วให้ Claude ช่วยแก้ตามสิ่งที่อ่านเจอ
- แก้ปัญหาที่พบบ่อย เช่น Build Error, ใส่ Environment Variables ไม่ครบ, สิทธิ์ในฐานข้อมูลยังไม่เปิด
- จำไว้เสมอว่าแก้ Environment Variables แล้วต้อง Redeploy ค่าใหม่จึงมีผล
- ตรวจสอบว่าแอปใช้งานได้จริงบน URL สาธารณะ

### แฟ้มข้อมูลเพิ่มเติม

- การผูกโดเมนของตัวเอง
- การแยก Environment ระหว่าง Preview และ Production
- ทางเลือกอื่นในการ Deploy

### ผลลัพธ์ของภารกิจ

เอเจนต์มี URL จริงที่ใช้งานได้ พร้อมโพสต์แชร์ในกลุ่ม Claude Code Thailand

## ภารกิจที่ 10 - ประกอบ Workflow และส่งผลงานขึ้นเว็บจริง

### อุปกรณ์ที่ต้องใช้ในภารกิจนี้

Claude Code CLI · แฟ้มบริบท CLAUDE.md · การคุมบริบท · Plan Mode และ Agentic Loop · Skill ของตัวเอง · Git · MCP · Vercel

### เส้นทางปฏิบัติการที่ต้องประกอบขึ้น

**Feature ใหม่ที่อยากเพิ่ม** → **ให้ Claude สัมภาษณ์จนโจทย์ชัด** → **วางแผนด้วย Plan Mode** → **ตรวจแผนและอนุมัติ** → **ลงมือตาม Agentic Loop** → **เรียก Skill ของตัวเองตรวจงาน** → **Git Commit และ Push** → **Vercel Deploy อัตโนมัติ แอปบน URL จริงอัปเดตทันที**

### ปฏิบัติจริงในคาบ

### ผลลัพธ์ของภารกิจ

ปิดปฏิบัติการด้วยแอปที่ใช้งานได้บน URL จริง และ Workflow ที่วนใช้ต่อได้ทุกวัน

## แฟ้มลับที่ยังไม่เปิดในปฏิบัติการนี้

เพื่อให้เวลา 10 ชั่วโมงเพียงพอสำหรับเอเจนต์หน้าใหม่ และยกเวลาไปให้การสร้างผลงานจริง จึงปิดผนึกแฟ้มต่อไปนี้ไว้ก่อน ทั้งหมดอยู่ในหลักสูตรเต็ม 12 บทเรียน

- **Hooks** สั่งให้ระบบทำอะไรอัตโนมัติทุกครั้งที่ถึงจังหวะหนึ่งในการทำงานของ Agent เช่น แจ้งเตือนหรือรันตรวจงานเอง
- **Subagents** แตกงานที่ไม่ใช่งานหลักออกไปให้ Agent ลูกทำ เพื่อไม่ให้บริบทของตัวหลักบวม
- **Agent Teams** ทีม Agent หลายตัวที่คุยกันเองและแบ่งงานกันได้ ยังเป็นฟีเจอร์ทดลองและใช้ทรัพยากรสูง
- **Automation, Headless Mode และ CI/CD** ให้ Claude Code ทำงานเองโดยไม่ต้องมีคนสั่ง
- **Plugins และการวาง Environment มาตรฐานให้ทั้งทีม**
- **MCP ขั้นสูง** เชื่อมฐานข้อมูลและ API ภายในขององค์กร

## เมื่อภารกิจสำเร็จ เอเจนต์จะได้อะไร

- **ใช้ AI Coding Agent ได้จริง** สั่ง Claude Code อ่าน วิเคราะห์ และแก้ไขโค้ดผ่าน Terminal ได้ด้วยตัวเอง
- **คุมค่าใช้จ่ายและบริบทเป็น** รู้ว่าเมื่อไรควรล้าง เมื่อไรควรย้อน และควรใช้โมเดลไหนกับงานแบบใด
- **ควบคุม AI ได้ ไม่ใช่แค่ลุ้นผลลัพธ์** เข้าใจ Plan Mode และ Agentic Loop
- **ร่องรอยการทำงานที่อ่านรู้เรื่อง** ตรวจ Code Change เขียน Commit Message และสร้าง Pull Request ได้เร็วขึ้น
- **อาวุธประจำตัวที่ใช้ได้จริง** Skill ที่เปลี่ยนคำอธิบายที่พิมพ์ซ้ำทุกวันให้เป็นความสามารถถาวรของ AI
- **สร้างแอปจากศูนย์ได้เอง** พร้อมต่อเครื่องมือภายนอกผ่าน MCP
- **ผลงานออนไลน์ที่แชร์ได้** แอปที่ Deploy แล้วบน URL จริง ใส่ Portfolio ได้ทันที
- **เห็นแฟ้มที่ยังไม่เปิด** รู้ว่า Hooks, Subagents, Agent Teams และ Automation คืออะไร และควรกลับมาเปิดเมื่อไร

## ภารกิจขั้นต่อไป

เอเจนต์ที่ต้องการไต่ระดับต่อสามารถเข้าร่วมหลักสูตรเต็ม **Claude Code Roadmap 12 บทเรียนจากพื้นฐานสู่ AI Coding Workflow** ซึ่งเปิดแฟ้มเพิ่มเติมดังนี้

- Hooks และการสั่งให้ระบบทำงานอัตโนมัติตามจังหวะการทำงานของ Agent
- Subagents สำหรับแตกงานออกไปไม่ให้บริบทของตัวหลักบวม
- Agent Teams ทีม Agent ที่คุยกันเองและแบ่งงานกันได้
- ลงมือทำ Automation, Headless Mode และ CI/CD Pipeline จริง
- Plugins, Custom Commands และการวาง Environment มาตรฐานให้ทั้งหน่วย
- การเชื่อม MCP กับ Database และ API จริงขององค์กร
- Capstone Project แบบ Multi-Agent เต็มรูปแบบ

หลักสูตรเต็มมี 2 รูปแบบให้เลือก คือ Onsite 5 วัน 30 ชั่วโมง และ Online 5 วัน 15 ชั่วโมง

## รูปแบบการฝึก

ปฏิบัติการนี้เน้น **ดูผู้บัญชาการทำ แล้วลงมือตามไปพร้อมกัน** เหมาะกับเอเจนต์หน้าใหม่ที่ยังไม่คุ้นกับอุปกรณ์ ผู้เข้าร่วมไม่ต้องท่องคำสั่ง แต่จะได้เห็นว่าผู้บัญชาการคิดอย่างไรก่อนพิมพ์แต่ละคำสั่ง

ตลอด 5 วัน เอเจนต์จะเห็นพัฒนาการของตัวเองจาก

**คนที่ไม่เคยใช้ AI Coding Agent** → **เอเจนต์ที่สั่ง AI ลุยโค้ดได้และคุมค่าใช้จ่ายเป็น** → **เอเจนต์ที่มีแอปของตัวเองขึ้นออนไลน์จริง**

## อุปกรณ์ที่ต้องเตรียมก่อนออกภารกิจ

- โปรเจกต์เล็ก ๆ ของตัวเอง 1 โปรเจกต์ (ถ้าไม่มี ผู้บัญชาการเตรียมตัวอย่างให้)
- บัญชีฟรีที่ทยอยสมัครตามวันที่ใช้: GitHub ก่อน Day 3 · Supabase ก่อน Day 4 · Vercel ก่อน Day 5 (Supabase และ Vercel ล็อกอินด้วยบัญชี GitHub ได้)

- Node.js รุ่น LTS ติดตั้งก่อน Day 4 (ตัวติดตั้ง Claude Code ไม่ได้ใช้ Node.js แล้ว จึงยังไม่ต้องลงตั้งแต่ Day 1)
- แนะนำให้ใช้จอภาพ 2 จอ หรือแบ่งครึ่งจอ เพื่อดูหน้าจอผู้บัญชาการและพิมพ์ตามไปพร้อมกันได้

## Briefing ก่อนออกภารกิจ (ประมาณ 30 นาที)

ปฏิบัติการนี้ **ไม่ให้ติดตั้งทุกอย่างรวดเดียว** แต่ทยอยลงตามวันที่ได้ใช้จริง ก่อน Day 1 เตรียมแค่ 5 ข้อนี้

1. เตรียมบัญชีสำหรับใช้งาน Claude Code ให้ล็อกอินได้ก่อนเข้าคาบ (ข้อนี้สำคัญที่สุด เป็นสิ่งเดียวที่ทำให้ตามคาบแรกไม่ได้ถ้าไม่พร้อม)
2. ติดตั้ง Git และตรวจสอบว่ารันคำสั่ง `git --version` ได้ (ผู้ใช้ Windows ให้ติดตั้ง Git for Windows เพราะ Claude Code เรียกใช้ Bash tool ผ่านตัวนี้ ส่วน macOS และ Linux มีมาให้แล้ว)
3. เตรียมโปรเจกต์เล็ก ๆ ของตัวเองไว้ 1 โปรเจกต์ (ถ้าไม่มี ผู้บัญชาการเตรียมโปรเจกต์ตัวอย่างให้)
4. เตรียม Code Editor ที่ถนัด เช่น VS Code
5. ทดสอบเข้าห้องปฏิบัติการออนไลน์และการแชร์หน้าจอ

**ยังไม่ต้องติดตั้ง Node.js ก่อน Day 1** เพราะตัวติดตั้ง Claude Code รุ่นปัจจุบันไม่ได้ใช้ Node.js แล้ว จะได้ใช้จริงตอนสร้างแอปใน Day 4
