# Borrow Buddy

ระบบบันทึกของที่เจ้าของให้เพื่อนยืม ว่าใครยืมอะไร เมื่อไร ต้องคืนเมื่อไร และคืนแล้วหรือยัง

## Language

**เจ้าของ (Owner)**:
คนเดียวที่ใช้ระบบ เป็นผู้บันทึกและจัดการการยืมทั้งหมด
_Avoid_: ผู้ใช้, แอดมิน, ผู้ให้ยืม

**เพื่อน (Friend)**:
คนที่มายืมของจากเจ้าของ ระบุด้วยชื่อเล่นที่พิมพ์ในแต่ละการยืม ไม่มีทะเบียนรายชื่อแยก
_Avoid_: ผู้ยืม, ลูกค้า, borrower

**ของ (Item)**:
สิ่งของจับต้องได้ที่เจ้าของให้ยืม ไม่รวมเงิน
_Avoid_: สินทรัพย์, สิ่งของยืม

**การยืม (Loan)**:
หนึ่งบันทึกที่ระบุว่าเพื่อนหนึ่งคนยืมของหนึ่งรายการ พร้อมวันที่ยืม กำหนดคืน และวันที่คืนจริง ถ้ายืมหลายชิ้นให้บันทึกเป็นหลาย Loan
_Avoid_: รายการยืม, Borrow, Transaction

**วันที่ยืม (Borrowed Date)**:
วันที่เพื่อนรับของไปจากเจ้าของ
_Avoid_: วันเริ่มยืม

**กำหนดคืน (Due Date)**:
วันที่เพื่อนต้องคืนของ ทุก Loan ต้องมีเสมอ
_Avoid_: วันครบกำหนด, deadline

**วันที่คืนจริง (Returned Date)**:
วันที่เพื่อนคืนของจริง ว่างไว้จนกว่าจะกดคืน
_Avoid_: วันคืน

**คืนแล้ว (Returned)**:
การที่เจ้าของยืนยันว่า Loan นั้นได้รับของคืนแล้ว โดยระบุวันที่คืนจริง และยกเลิกการยืนยันได้หากกดผิด
_Avoid_: ปิดรายการ, เสร็จสิ้น

## สถานะของ Loan

**ยังไม่คืน (Outstanding)**:
Loan ที่ยังไม่ Returned และยังไม่เลยกำหนดคืน รวมถึงวันที่ถึงกำหนดคืนพอดี
_Avoid_: กำลังยืม, Active

**เกินกำหนด (Overdue)**:
Loan ที่ยังไม่ Returned และผ่านวันกำหนดคืนไปแล้ว
_Avoid_: ค้างคืน, Late

**จำนวนวันเกินกำหนด (Days Overdue)**:
จำนวนวันตั้งแต่วันกำหนดคืนจนถึงวันนี้ ใช้กับ Loan ที่เป็น Overdue เท่านั้น
_Avoid_: วันล่าช้า, Late Days

**คืนแล้ว (Returned)**:
Loan ที่มีวันที่คืนจริงแล้ว
_Avoid_: Closed
