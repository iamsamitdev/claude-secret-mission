===
2. Second Project
===
Step 1: grill
---
/grill-with-docs ผมอยากทำเว็บบันทึกของที่ให้เพื่อนยืม บันทึกว่าใครยืมอะไร เมื่อไร ต้องคืนเมื่อไร และกดว่าคืนแล้วได้ ช่วยซักถามผมทีละข้อจนศัพท์และขอบเขตชัด แล้วสรุปลง CONTEXT.md ห้ามเขียนโค้ด โปรเจ็กต์ใหม่นี้จะสร้างทุกอย่างในโฟลเดอร์ borrow-buddy

Step 2: design
---
/plan จากไฟล์ @borrow-buddy\CONTEXT.md และ @borrow-buddy\CLAUDE.md  คุณช่วยเขียนไฟล์ design.md สำหรับงานนี้ โดยสอบถามความต้องการฉันเป็นข้อๆ ให้ฉันตอบ

Step 3: task.md
---
อ่าน @borrow-buddy\@CONTEXT.md และ @borrow-buddy\@design.md แล้ววางแผนสร้างไฟล์ Tasks.md สำหรับการ implement ต่อไป

Step 4: git manage with sub agent
---
สร้าง subagent สำหรับ git management

[ออกจาก claude /exit แล้วเข้าใหม่]

Step 5: use git manager subagent
---
ใช้ git-manager ในการจัดการงานเกี่ยวกับ git
ทำการ initial git repository โปรเจ็กต์ @borrow-buddy
สร้าง .gitignore และ commit แรกได้เลยครับ

Step 6: implement tasks
---
เริ่มสร้างโปรเจ็กต์ Tasks.md เมื่อเสร็จแต่ละ task ให้ทำการ git commit ไว้ด้วย

Step 7: Handoff
---
วันนี้เอาไว้เท่านี้ก่อน ก่อนจะจากกันใน session นี้ ให้คุณช่วยเขียนสรุป handoff markdown file งานนี้ไว้ให้ทำงานต่อในวันถัดไปได้ด้วยครับ
